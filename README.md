# Pankaj Foolwani — Premium Multi-Page Business Website (Next.js Edition)

An ultra-premium, modern, and high-performance corporate multi-page web platform for **Pankaj Foolwani** (Entrepreneur, Strategic Business Consultant, and Founder of Foolwani Enterprises).

Built as an elevated, executive-grade advancement of [pankajfoolwani.com](https://pankajfoolwani.com/), incorporating **100% of the reference site's details, credentials, and brand essence** while introducing a clean, modern **Light / Dark theme system** and a full **Multi-Page Architecture**.

---

## 🎨 New Theme System (Light & Rich Midnight Dark)

The website now features a modern executive theme with an instant **Theme Switcher** (☀️ / 🌙) in the navigation header:
- **Executive Light Theme (Default):** Crisp modern porcelain (`#f8fafc`), clean white glass cards with soft elevated shadows, slate navy typography (`#0f172a`), warm champagne gold accents (`#b8860b`), and subtle micro-grids — reflecting the aesthetic of top global advisory firms (McKinsey, BCG, Goldman Sachs).
- **Executive Dark Theme:** Rich midnight navy-slate (`#0a0f1d`), slate cards (`#111827`), glowing gold accents (`#d4af37`), and refined amber highlights.

## 🛠️ Technology Stack

- **Framework:** Next.js 14.2+ (App Router, Server & Client Components)
- **Language:** TypeScript 5.6+
- **Styling:** Tailwind CSS 3.4+ with custom dual-theme tokens
- **Icons:** Lucide React
- **Typography:** Playfair Display (Serif) + Plus Jakarta Sans (Sans-serif)
- **State Management:** React Context (`LanguageContext` & `ThemeContext`)
